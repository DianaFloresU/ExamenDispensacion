# Backend - Sistema de Admisión Académica (NestJS)

Backend desarrollado en NestJS y TypeORM conectado a PostgreSQL para la gestión del sistema de admisión.

## 🚀 Requisitos previos
Asegúrate de tener instalado en tu computadora:
* [Node.js](https://nodejs.org/) (Versión LTS recomendada)
* [Docker Desktop](https://www.docker.com/) (Para la base de datos PostgreSQL)
* Un cliente HTTP como [Thunder Client](https://www.thunderclient.com/) o Postman.
